COMMON QUESTIONS

How can we help?

How is the Student Success Score calculated?

It is a weighted 0–100 score using CGPA (20%), attendance (15%), LMS (15%), engagement (10%), coding (10%), skills (10%), placement readiness (10%), and feedback (10%). The Analytics page shows the scoring method.

What do HIGH, MEDIUM, and LOW risk mean?

Academic risk bands are based on the overall score: HIGH is below 60, MEDIUM is 60 to below 80, and LOW is 80 or above. Placement risk is classified separately. These are rules-based support signals, not a validated prediction.

Are Action Center notes shared with the college?

No. This demo stores follow-up notes in this browser only. There are no staff accounts or shared secure storage, so do not enter sensitive personal or student information.

Does importing a CSV upload my data?

No. CSV validation and preview happen in your browser. Import changes the current dashboard view for this session; refreshing returns to the backend dataset.

Why is there no historical trend for a student?

The current dataset contains one current record per student, not semester-by-semester history. The dashboard avoids inventing trends or subject-level details that are not in the source data.

What should I do if the backend is offline?

Check the System Status indicator and reload after the API is available. Imported CSV data is temporary and does not replace or repair the backend dataset.
